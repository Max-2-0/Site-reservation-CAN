# Compagnie Alsacienne de Navigation (CAN)

A website project created during the first year of a Bachelor's degree in Computer Science (BUT Informatique). It is an interface prototype for a navigation company, designed around viewing and managing ferry crossing reservations.

## Overview

The website brings together several screens for a reservation journey:

- a homepage introducing the company;
- a boarding pass mockup;
- an invoice mockup;
- a dashboard designed to monitor crossing occupancy;
- an experimental reservation form in the `test/` folder.

The form in `test/reservation.html` lets users add passengers and vehicles. When submitted, it displays a JSON preview of the reservation on the page. The other screens are mostly mockups, and some content still needs to be completed.

## Technologies

- HTML
- CSS
- JavaScript

## Run the project

No installation is required to view the static pages. Open `index.html` in a browser.

To try the reservation form, open `test/reservation.html`.

## Prototype limitations

This project is a front-end mockup created for educational purposes. The form generates a JSON preview, but it does not send it to a server, and reservations are not saved. The invoice, boarding pass, and dashboard pages still contain demonstration content or information to be completed.

# Compagnie Alsacienne de Navigation (CAN)

Projet de site web réalisé en première année de BUT Informatique. Il s'agit d'un prototype d'interface pour une compagnie de navigation, imaginé autour de la consultation et de la gestion de réservations de traversées.

## Présentation

Le site regroupe plusieurs écrans autour d'un même parcours de réservation :

- une page d'accueil présentant la compagnie ;
- une maquette de carte d'embarquement ;
- une maquette de facture ;
- un tableau de bord destiné au suivi du remplissage des traversées ;
- un formulaire de réservation expérimental dans le dossier `test/`.

Le formulaire de `test/reservation.html` permet d'ajouter des passagers et des véhicules. À la validation, il affiche un aperçu JSON de la réservation dans la page. Les autres écrans sont principalement des maquettes et certains contenus restent à compléter.

## Technologies

- HTML
- CSS
- JavaScript

## Lancer le projet

Aucune installation n'est nécessaire pour consulter les pages statiques. Ouvrez `index.html` dans un navigateur.

Pour essayer le formulaire de réservation, ouvrez `test/reservation.html`.

## Limites du prototype

Ce projet est une maquette front-end réalisée dans un contexte pédagogique. Le formulaire construit un aperçu JSON, mais celui-ci n'est pas envoyé à un serveur et les réservations ne sont pas enregistrées. Les pages de facture, de carte d'embarquement et de tableau de bord contiennent encore des éléments de démonstration ou des informations à compléter.
